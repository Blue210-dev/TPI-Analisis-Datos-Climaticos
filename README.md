## Descripción del Dataset
Se utilizó el dataset oficial `annual.csv` proveniente del análisis climático global GISTEMP. El archivo contiene los registros históricos de las anomalías medias anuales de temperatura global, permitiendo identificar las tendencias de calentamiento a lo largo de las décadas.

## Estructura del Repositorio
* `/datos`: Contiene el archivo origen `annual.csv`.
* `/scripts`: Contiene el código de procesamiento `analisis_datos.py`.
* `/resultados`: Contiene el gráfico evolutivo generado `grafico_clima.png`.

## Instrucciones de Ejecución
1. Abrir el entorno de Google Colab.
2. Clonar este repositorio.
3. Asegurarse de tener la librería `pandas` y `matplotlib` instaladas.
4. Ejecutar el script con el comando: `python scripts/analisis_datos.py`.
